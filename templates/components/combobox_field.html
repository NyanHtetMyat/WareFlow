{% comment %} Reusable searchable-dropdown field. IMPORTANT: show_label and show_search_icon must be passed EXPLICITLY by every caller (True or False) — do not rely on a default. Django's |default: filter treats explicit False the same as "not provided" and silently substitutes the fallback, which previously caused Zone/Rack/Bin to keep rendering as if these flags were never set to False at all. Being explicit here is the actual fix, not a style preference. Pass `errors` (e.g. form.product.errors) only when this field owns its own .form-field wrapper (show_label=True), so the error message renders INSIDE that wrapper instead of as a stray sibling div with mismatched margin. Bare comboboxes (show_label=False — Zone/Rack/Bin) don't take `errors`; their parent page already wraps them in its own .form-field and handles the single shared Location error itself.
